# 100 Zero-Ad-Spend Acquisition Tactics & Open-Source Tool Engine

## Strategic North Star
Expand Revora through reuse: turn the same tested open-source tools into internal platform improvements, free customer-facing resources, and paid implementation services—without spending money on ads or burning unbudgeted AI inference tokens.

## The 4 Meanings of "Free" (Strict Economic Boundaries)
1. **Organic Channel**: No paid advertising; costs time, moderation, and software execution.
2. **Open-Source Software**: Code is free to license; still requires compute, storage, and maintenance.
3. **Hosted Free Tier**: Limited usage allowance; requires hard stops before overages.
4. **Free Offer to Prospects**: Prospect pays $0; Revora absorbs delivery cost, so delivery must be near-zero marginal cost (deterministic code).

## The 6 Concrete Revora Systems Built from GitHub Tools
1. **System 1: Website Inspection Service** (Playwright + axe-core + Lighthouse)
   - Objective URL inspection checking mobile viewport, tap target sizes, load latency, and contact links.
2. **System 2: Platform Reliability Assistant** (Vitest + Sentry + Playwright synthetic journeys)
   - Continuous monitoring of public routes (`/`, `/auth`, `/pricing`, `/portal`) with automated alerts before customers encounter issues.
3. **System 3: Private Concept & Implementation Plan** (Sol creative brief + headless renderer)
   - High-craft private demo generated for qualified prospects without publishing or creating live DNS.
4. **System 4: Free Resource -> Saved Workflow** (Local calculators + printable work orders)
   - Prospect uses tool $\to$ downloads PDF or saves state $\to$ auto-provisions trial workspace preloaded with their data.
5. **System 5: Model Quality & Cost Control** (Promptfoo + LiteLLM / Lovable AI router)
   - Benchmarking models across Sol/Terra/Luna roles, ensuring lowest token cost for routine extraction and reserving advanced reasoning for design synthesis.
6. **System 6: Permissioned Research & Qualification** (OSM Nominatim + Cheerio extraction)
   - Grounded business discovery bounded by rate limits (< 1 req/sec) and persistent geocoding cache.
